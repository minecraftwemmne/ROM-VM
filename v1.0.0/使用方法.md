# 使用方法
# mov {寄存器}, {内存} 将寄存器写入内存
# cw {值}, {寄存器}向寄存器赋值
# rd {寄存器}, {寄存器}将寄存器向寄存器赋值
# cls {寄存器}清理寄存器
# ret 跳出函数
# inj {内存}, {寄存器}将内存向寄存器赋值
# clns {内存}清理内存
# int {寄存器}将寄存器转为int型
# str {寄存器}将寄存器转为str型
# ad {+, -, *, /}, {寄存器}, {寄存器}, {寄存器}加减乘除运算
# jmp {数字/函数}跳转至第x行或指定函数(x从0开始)
# sleep {整数}挂起线程x秒
# in {寄存器}捕获用户输入
# stop 杀死程序
# cmp {寄存器}, {寄存器}比较两个寄存器至是否相符
# je {数字/函数}相等跳转
# jne {数字/函数}不相等跳转
# jge {数字/函数}大于跳转
# jle {数字/函数}小于跳转
# rad {最小值}, {最大值}, {寄存器}获取随机数
# print {内容/寄存器}直接输出
# pause 等待用户按回车
# push {寄存器}入栈
# pop {寄存器}出栈
# cls 清屏
# call {行号/函数名}调用函数
# nop 空指令
# not {寄存器}取反
# hlt 停机
# // 注释
